# Career Readiness & Skill Gap Platform - Frontend

This is the client web application for the **AI-Powered Career Readiness & Skill Gap Platform**, crafted according to the system blueprint.

## 📱 The 8 User Flow Pages (Matching the Blueprint)
1. **Home**: Landing page featuring the Problem & Solution, Target Audience cards, and Impact Metrics.
2. **Register / Login**: Authentication modal with 1-Click Instant Demo Login.
3. **Dashboard**: Central readiness hub with circular progress gauge, metric cards, and quick shortcuts.
4. **Upload Resume**: Drag-and-drop PDF resume upload zone, raw text input, and pre-loaded sample profiles for instant demo testing.
5. **Job Description**: 1-Click selector for popular tech job roles or custom JD analysis.
6. **Analysis & Roadmap**: 3-column breakdown of Matched, Missing, and Weak skills with a personalized 4-week learning roadmap and checkable task items.
7. **AI Quiz**: Timed MCQ assessments targeting missing skills with immediate evaluation and detailed explanations.
8. **Progress**: Real-time growth analytics with Canvas charts, gap reduction metrics, and report export.

## 🚀 How to Run the Frontend

### Method 1: Direct File Opening
Simply double-click `index.html` in Windows Explorer or open it in Google Chrome / Edge / Firefox!

### Method 2: Served via the Backend
When the Backend server is running (`npm start` in the `Backend` directory), the backend automatically serves the frontend at:
`http://localhost:5000`
